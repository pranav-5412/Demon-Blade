# DemonBlade

DemonBlade is a third-person action-adventure game built with Godot 4.7.1.

## Current Features

- Third-person character movement
- Camera-relative controls
- Tanjiro and Nezuko story progression
- Chapter 1 village and mountain journey
- Giyu encounter and combat tutorial
- Expanded Journey to Shizu mountain route
- Forests, ridges, valleys, slopes, cliffs, and switchbacks
- Collision-safe mountain traversal
- Shizu arrival cinematic
- Shizu training progression with 7 stages
- Breathing control system
- Water Breathing Forms 1–7
- Training dummies and combat drills
- Dodge, guard, light attack, and heavy attack mechanics
- Save checkpoints and scene resume support

## Training Progression

1. Movement and endurance
2. Dodge and reaction
3. Sword control
4. Breathing control
5. First Water Form tutorial
6. Water Form mastery
7. Final combined training course

Water Form 1 is unlocked at Stage 5. Forms 2–7 unlock progressively during Stage 6.

## Running the Game

1. Install Godot 4.7.1.
2. Clone this repository.
3. Open the project in Godot.
4. Run the project with **F6** or **F5**.
